# kiro-local-to-aws

Companion repository for the talk **"From Local to AWS: Build and Deploy with Kiro"**.

We use [Kiro](https://kiro.dev) to walk through Spec-Driven Development (SDD), run a tank game locally, and deploy it to AWS step by step.

## Agenda

1. What is Kiro?
2. Installation and credit management
   - Quick install steps
   - How university credits work and how to monitor token usage
3. Spec-Driven Development (SDD)
   - Spec-based workflow: `requirements.md`, `design.md`, and `tasks.md`
4. The base project (running locally)
   - Tank game walkthrough
5. Cloud deployment (live on AWS), step by step with Kiro
   - Ask Kiro to analyze the local game and propose a cloud architecture
   - Walk through the chosen services and the architecture flow
   - Have Kiro generate infrastructure as code (IaC) or deployment scripts
   - Provision resources and deploy to an AWS account until we get a public URL

## Status

Work in progress. The game, specs, and infrastructure code will be added as the talk material is built.
