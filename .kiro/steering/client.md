# Cliente

- JavaScript plano en el navegador, cargado con `<script type="module">`.
- El juego se dibuja en un único `<canvas>`.
- El cliente solo envía intenciones (teclas, disparo) y dibuja el estado que recibe del servidor.
- El HUD muestra vidas, puntaje y el ranking top 5.
